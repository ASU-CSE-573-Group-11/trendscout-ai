# Contribution Conventions

- Work in a focused branch named `name/module-short-description`.
- Keep one logical change per pull request.
- Describe input, output, test method, and known limitations in each module README.
- Never commit credentials or personal data.
- Preserve raw records; write normalized outputs separately.
- Add a source and license note for third-party code, libraries, models, and datasets.
- Request at least one teammate review before merging integration changes.
