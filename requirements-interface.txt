# Optional extras for Faisal's retrieval and interface module.

# a deterministic hashing encoder, the graph falls back to the in-memory
# backend, and answers fall back to the extractive provider. Install these only
# for the real dense baseline, the Streamlit UI, a live Neo4j, or an LLM answer
# provider.

# Real dense retrieval. Pulls in torch; large download.

# Faster dense search. numpy alone is enough; faiss is used when present.

faiss-cpu>=1.8.0

# Live graph backend, instead of the in-memory equivalent.

# LLM answer provider. Requires ANTHROPIC_API_KEY.
