Study overview

A bounded integration result

The graph is built from 45 retained source records covering five companies. Counts below describe nodes and links in this frozen study snapshot—not the full universe of each company’s activity.

Measured findings

Retrieval found the release note. It did not find the original questions.

Twenty-eight release-fact questions each have one supporting document, so Precision@5 cannot rise above 0.2. The bars are Recall@5: how often that document appears in the top five. The dense bar is a hashing encoder, not a sentence transformer.

Method

How the graph was produced

The integration preserves source identity and validation boundaries from collection through the live database.

Freeze sources

Funding pages, public job listings and weekly repository observations are retained with source URLs, hashes and observation clocks.

Project semantics

Source records become provenance-bound Claims, FundingRounds, JobPostings, Repositories, Investors, Skills and Technologies.

Validate RDF

The complete graph is exported as Turtle and checked against SHACL identity, datatype and relationship requirements.

Compare Neo4j

The live database reads the exact payload IDs and relationships. Its company summaries must equal the offline result.
